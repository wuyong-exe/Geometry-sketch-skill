# 几何题自动画图 (Geometry Sketch)

> 根据初中数学几何题的文字描述，自动生成准确的几何图形，输出 PNG + 可交互 HTML。

> **⚠ 输出位置（2026-08 交付规则）**：**用户提供目标文件夹时，所有中间过程文件（`.py` 脚本）与目标文件（`.png` 图片 + `.html`）统一放在用户指定的目标文件夹**；用户未提供时，**由 Agent 自行决定合理输出位置**（填写数据区 `output_dir`；不填则模板兜底当前目录下 `geometry_sketch/`）。**勿写死固定路径**。

> **⚠ 加载截断处理（必读）**：本文件是**导航骨架**（约 10KB），Reasonix 加载时若只返回开头片段，**完整代码与详细规则在同目录 `references/`**（已随 skill 分发，静态文件）：
> - `references/algorithms.py` —— 3.1 几何算法库（含 `eval_op` 求值器）【代码权威源】
> - `references/template_static.py` —— 4.1 静态模板（精确/示意/坐标系）【代码权威源】
> - `references/template_motion.py` —— 4.1b 动点模板（含 JS 交互内核）【代码权威源】
> - `references/rules.md` —— **阶段 0-5 详细规则**（模式判别、动点参数化、可动范围、方向惯例、轨迹名单、目标线段、构造策略、反馈表、op 表）【规则权威源】
> - `references/type-notes.md` —— 常见题型参考
>
> **执行流程：先按阶段 Read `references/rules.md` 对应章节，写脚本前 Read `references/algorithms.py` + 所选模板（照抄，不要凭经验重建）——截断不可怕，可怕的是不知道自己漏看了内容。模板较长需分段 Read（单次 Read 上限约 20K tokens，超限用 `offset/limit` 分段读；如 `template_motion.py` 含 JS 交互内核通常需分 3 段）**

### 硬规则速查（任何模型必须遵守，不可跳过）

| # | 规则 | 违例自查 |
|---|------|----------|
| 1 | **输出 PNG + HTML**，不输出独立 `.svg` 文件（HTML 内嵌 SVG 属正常功能，勿删） | 独立 `.svg` 文件是否生成？HTML 是否正确输出？ |
| 2 | **全部黑色 `#000000`，等宽 `LW=1.5`，默认全实线**。用户要求虚线时才用 `ls='--'`，且必须走「虚线拆线」规则 | 有没有 `'#2d3436'`、`'#636e72'`？有就改 |
| 3 | **默认不画标记**：等长标记、角度弧线一律不画；**直角标记（⊥）为可选项**——仅用户明确要求"标直角/标垂直"时：PNG 端对指定顶点调用 `draw_right_angle_mark`（或静态模板 `right_angle_marks` 数据驱动），HTML 端——动点模板填 `dynamics.right_angle_marks`（JS 实时跟随）、静态模板填数据区 `right_angle_marks`（generate_html 参数） | 有没有 `draw_angle_mark`、`draw_equal_length_mark`？有就删；`draw_right_angle_mark` / `right_angle_marks` 是否仅在用户要求时出现？ |
| 4 | **坐标算完必须验证**：`print` 每条约束的"实际值 vs 期望值" | 输出里有没有约束对比？没有就补 |
| 5 | **水平基准优先级**：坐标系 > 正方形/矩形/平行四边形长底边 > 最长线段（含圆时以实际最长线段为准，不机械取直径），图形主体朝上；**跨度大方向水平**（高瘦图形自动旋转 90° 横放，坐标系除外） | 坐标系是否固定？主图形是否是正方形/矩形/平行四边形？最长边是否水平（含圆时不误取直径）？高瘦图形是否横放（跨度大方向水平）？ |

**核心原则**：
- 不要凭空编坐标。每一步坐标计算必须有几何依据。
- **只画题设，不画结论**（2026-08）：结论（"下列结论/求证/证明/判断"后）中的射线/延长/特殊位置/最值辅助等图形本体不画——只按基础题干 + 扩展题干（"若/设"引入）绘图，防泄露答案；**求证中的基本几何元素该画**（被证明对象：点/线段/三角形/四边形，画出不泄露结果、方便辨认；≌/∥ 等关系结论不画）；**隐藏轨迹照常显示**（动点运动路径，见 trajectory 规则）；判别不确定时查 `type-notes.md` 完整示范（详见 rules.md §1.6）。
- 先想清楚构造顺序再写代码——这和尺规作图的思路一致。
- 所有长度单位保持一致；默认以题目给出的第一个已知边长为基准缩放。
- 如果题目存在多种情况（如点的位置可能在左侧或右侧），按惯例默认画出最典型情况（不额外标注"情况一"文字——只标点的字母，见硬规则；必要时再画第二张）。
- **方向归一化**：水平基准按硬规则 #5 的三级优先级执行；跨度大方向水平（y 跨度 > 1.2×x 跨度时自动旋转 90°）仅作用于非坐标系/动点模式（坐标系 x 轴水平规则优先）。

## 工作流骨架

```
题目文字 → [阶段0] 意图识别 → [阶段1] 解析几何元素 → [阶段2] 确定构造顺序 → [阶段3] 计算坐标 → [阶段4] 绘图 → 输出 PNG + HTML → [阶段5] 如有反馈则迭代修改
```

- **阶段 0 意图识别与模式选择**：精确（默认）/示意（约束严重不足）/坐标系/动点 四模式判定——判别细则、示意默认值、询问规则、动点三类圆判定、curve 硬约束、**动点语义扩展**（几何对象上"一点"+条件求值→动点，2026-08）、模板选择 → **`references/rules.md` §阶段 0**。模式→模板：非动点（精确/示意/坐标系）→ 4.1 静态模板；动点 → 4.1b 动点模板。
- **阶段 1 解析几何元素**：点/形状/约束/辅助元素/动点参数化/关联点识别 → **`references/rules.md` §阶段 1**
- **阶段 2 确定构造顺序**：策略 A 水平基准 / B 直角顶点 / C 对称轴；动点层级（active/deps）→ **`references/rules.md` §阶段 2**
- **阶段 3 计算坐标**：3.2 执行规范、3.3 常见构造模式、3.4 op 表（`symmetry`/`reflect`/`midpoint`/`line_through_intersect` 等）→ **`references/rules.md` §阶段 3**；算法库代码 → `references/algorithms.py`
- **阶段 4 绘图**：**照抄模板**——静态模式 `references/template_static.py`，动点模式 `references/template_motion.py`（含数据区/dynamics/JS 内核）
- **阶段 5 反馈迭代**：5.1 迭代原则、5.2 反馈解读表 → **`references/rules.md` §阶段 5**

### ⚠ 模板不自包含（必读）

4.1/4.1b 模板**不独立运行**——调用 3.1 算法库的公共函数 `dist` `vec` `normalize` `rotate_point` `draw_right_angle_mark`（4.1b 加 `midpoint`）。**写脚本时必须把 `references/algorithms.py` 全文拼在脚本开头**，再拼所选模板（数据区 → 绘图执行区 → generate_html 调用），否则运行报 `NameError: name 'dist' is not defined`（实测踩中）。**⚠ 模板须整文件逐行复制**：模板**自身内部辅助函数**（`_restore_full_edges`/`compute_dynamic_extent`/`check_open_coverage`/`auto_label` 等，定义在数据区与预处理区/绘图执行区之间）也必须完整保留，**勿重组/删减模板内部函数**——"以为算法库拼了就够、模板内部函数可随重组删减"是踩坑模式（漏掉 `_restore_full_edges` 会 `NameError: name '_restore_full_edges' is not defined`）。

### ⚠ 拼接与执行注意（2026-08）

- **拼接锚点**：模板数据区/预处理区标记为 `# ============ 🧩 数据定义区/预处理区…`（`#` 后接 `=` 与 emoji），构建脚本**勿用 `# 数据定义区` 前缀锚定**（匹配不上）；建议用 `points = {`（数据区起点）或 `def _restore_full_edges`（内部函数起点）作锚点。

### 执行流程

1. Read `references/rules.md` 按阶段读对应章节；Read `references/algorithms.py` + 所选模板
2. **写脚本**：`references/algorithms.py` 完整内容 + 模板 → 写入输出位置（用户指定目标文件夹，或 Agent 决定）`geometry_sketch.py`

4. **🛑 自检**：对照硬规则速查表逐条核验（1 只出 PNG+HTML / 2 全黑等宽实线 / 3 无标记除非用户要求 / 4 打印约束验证 / 5 最长边水平、高瘦图形横放）

6. 阶段交接交付物格式 → `references/rules.md` §执行流程总结
