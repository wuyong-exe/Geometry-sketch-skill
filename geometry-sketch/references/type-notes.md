## 常见题型参考

下面是一些典型题目的构造方案，帮助快速判断构造策略：

### 三角形

- **SSS（三边已知）**：AB 放 x 轴 → C 用两圆交点
- **SAS（两边夹角）**：AB 放 x 轴 → AC 用旋转 + 缩放
- **ASA（两角夹边）**：AB 放 x 轴 → 分别从 A、B 以给定角度画射线 → 交点为 C
- **等腰 AB=AC**：BC 放 x 轴 → A 在 BC 垂直平分线上，高度由其他条件确定
- **直角 ∠A=90°**：A 放原点 → AB、AC 沿坐标轴 → B、C 由长度确定
- **等边三角形**：同 SSS，三边相等

### 四边形

- **平行四边形**：A、B 放 x 轴 → C = B + AD → D 由其他条件
- **矩形**：A 放原点 → AB 沿 x 轴 → AD 沿 y 轴
- **正方形**：同矩形，AB = AD
- **菱形**：对角线垂直平分 → 沿坐标轴放对角线
- **梯形 AB∥CD**：AB 放 x 轴 → C、D 的 y 坐标相同 → x 由腰长或角度确定

### 圆

- **已知圆心+半径**：直接放置
- **已知直径两端**：圆心 = 中点，半径 = 半长
- **三点共圆**：用三角形的外接圆（中垂线交点定圆心）
- **内切圆**：两条角平分线交点定圆心（内心），半径 = 内心到任一边的垂距（`foot_of_perpendicular`）
- **圆弧/扇形**：`arc_points(圆心, 半径, θ0, θ1)` 采样弧点（逆时针，θ 弧度）；扇形再连两条半径
- **切线和弦**：利用垂直关系（切线 ⊥ 半径）

### 翻折 / 对称

- **点关于线段翻折**：`H = foot_of_perpendicular(P, A, B)` → `P' = 2*H - P`
- **⚠ 验证判据（3 条，2026-08）**：翻折沿对称轴**直线**对称——① `dist(折痕端点, P) = dist(折痕端点, P')`；② `P P' ⊥ 对称轴`（点积≈0）；③ **P P' 中点 H 在对称轴直线上**（叉积共线，**含延长线**，勿用线段内判断——H 可落在折痕线段外）
- **翻折命名按位置对应**（如 ABCM → EFCM 即 A→E, B→F, C→C, M→M），验证失败先查对应关系
- **沿翻折线构造**：先画原图形，再逐点翻折，翻折后图形整体镜像

## 题设-结论区分（完整示范，2026-08）

> 判别题设（画）与结论（不画）的权威参考——rules.md §1.6 精简判别不确定时查本节。

**示例题目**：如图，在正方形ABCD中，AB＝4，对角线AC上的有一动点P，以DP为边作正方形DPFG．下列结论：①在P点运动过程中，F点始终在射线BC上；②在P点运动过程中，∠CPD可能为135°；③若E是DC的中点，连接EG，则EG的最小值为√2；④△CDP为等腰三角形时，AP的值为2√2或4√2－4．其中结论正确的是。

**三步拆分**：

| 步骤 | 内容 | 画/不画 | 为什么 |
|------|------|---------|--------|
| ① 基础题干 | 正方形 ABCD、AB=4、动点 P 在 AC 上、以 DP 为边作正方形 DPFG | **画**（全部） | 图形本体，题目给定 |
| ② 扩展题干 | "若 E 是 DC 的中点，连接 EG" | **画**（E 点 + EG 连线） | "若…"条件式引入，是题目的分析对象（帮助学生理解③） |
| ③ 结论 | ①F 始终在射线 BC 上；②∠CPD 可能 135°；③EG 最小值 √2；④△CDP 等腰时 AP 值 | **不画**（结论对象） | 学生需自行分辨/求证，画了泄露答案 |

**逐条判别细节**：
- **结论①"F 始终在射线 BC 上"** → **不画射线 BC**（作为可见实线）——只画正方形本体边 **BC 线段**（射线是待证明结论的图形本体）。**F 的隐藏轨迹照常显示**（trajectory 含 F，2026-08 修正）——轨迹是动点运动路径的自然呈现（虚线、可交互），学生拖 P 观察 F 随动运动、自行发现"F 在 BC 上"，正是题目考察的能力；"不画结论"只约束可见实线（射线 BC），不约束隐藏轨迹
- **结论②"∠CPD 可能为 135°"** → 不画特殊角度的构型（∠CPD 是普通角，其度数关系是结论）
- **结论③"EG 的最小值为 √2"** → EG 由扩展题干画（连接线）；"最小值"是最值结论，**不画最值辅助构造**（如 EG 最短时的特殊位置）
- **结论④"△CDP 等腰时 AP 值"** → 不画等腰的特殊位置（AP 的取值是结论）

**最终图形构成**：正方形 ABCD（4 边）+ 对角线 AC + 动点 P（在 AC 上）+ 正方形 DPFG + E（DC 中点）+ 连线 EG。**不含**射线 BC、特殊角度/等腰构型、最值辅助线。

**判别口诀**：题干给的全画（含"若/设"扩展），结论里的延伸/轨迹/特殊构造不画；分不清时先查本节，再保守"题设才画"。

## 求证类示例（基本元素该画，2026-08）

> 求证/结论中的**基本几何元素**（被证明对象：点/线段/三角形/四边形）该画——证明载体，画出不泄露结果、方便学生辨认；**关系/结果**（≌/∥/⊥/相似/最值/特殊位置）不画。

**示例题目**：如图，已知四边形 ABCD 为平行四边形，点 M、N 在对角线 BD 上，且 BM＝DN．求证：（1）△ABM≌△CDN；（2）AM∥CN．

**判别**：
| 内容 | 画/不画 | 为什么 |
|------|---------|--------|
| 基础题干：平行四边形 ABCD、对角线 BD、M/N 在 BD 上、BM=DN | **画** | 图形本体 + 题设条件 |
| 求证(1)△ABM≌△CDN 的**基本元素**（△ABM、△CDN 各边） | **画** | AB/CD/BM/DN 已在题干；**补画 AM、CN**——学生需辨认这两个三角形才能证明，画出不泄露全等结果 |
| 求证(1)的 **≌（全等）关系** | **不画** | 全等是证明的结论，不标全等标记 |
| 求证(2)AM∥CN 的 **∥（平行）关系** | **不画** | 平行是证明的结论，不标平行标记（AM、CN 线段本身已画） |

**最终图形构成**：平行四边形 ABCD + 对角线 BD + M、N（在 BD 上，BM=DN）+ 连线 AM、CN。**不含**全等/平行标记。

**原则**：画出基本元素（三角形、线段）不会透露证明结果——学生通过辨认图形元素、结合条件才能推出全等/平行；关系/结果标记（≌/∥/特殊构型）才是答案，不画。

## 构型即结论示例（图形自然呈现关系可接受，2026-08）

> 求证类中，"构型即结论"——当题设本身确定了某构型（如求证 △XYZ 为等腰三角形，而题设构造使 XYZ 天然等腰），**图形自然呈现该形态是可接受的**（学生仍需结合条件证明）；"不画"指**不标关系标记**（等腰/等边/直角的标记符号）与**不构造题设之外的特殊辅助**。

**示例**：已知 △ABC 中，AB=AC，D 在 BC 上，AD⊥BC．求证：△ABD≌△ACD．

**判别**：
| 内容 | 画/不画 | 为什么 |
|------|---------|--------|
| △ABC（AB=AC 等腰）、D 在 BC 上、AD⊥BC | **画**（题设） | AB=AC 使图形自然呈等腰形态；AD 是题设给的高线 |
| △ABD、△ACD（求证对象的基本元素） | **画** | 学生需辨认两个三角形才能证明全等 |
| ≌（全等）、⊥（垂直）标记 | **不画** | 全等/垂直是证明结论（AD⊥BC 虽是题设，但不标垂直记号——默认不标标记，硬规则 3） |

**要点**：题设 AB=AC 自然画出等腰形态、AD 画高线——图形"看起来"有这些关系是**题设给定**的（学生从题干知道），不算泄露；泄露的是"△ABD≌△ACD 的证明结论"，通过不标标记保护。

## 注意事项

1. **坐标不要太小或太大**：尽量让图形在 5-15 单位范围内，方便 matplotlib 处理。
2. **避免点重叠**：如果计算出的两个点距离 < 0.02，考虑调整构造策略。
3. **默认全实线**：主干线和辅助线统一实线。用户要求虚线时才用 `ls='--'`，且必须走 4.2「虚线拆线」规则避免被实线遮盖。
4. **中文支持**：如果需要在图中添加中文说明（如"情况一"），确保系统有中文字体。
5. **如果题目不完整**：某些约束缺失导致图形不唯一时，选择最自然的默认值（如等腰三角形且未给顶角时，取 60° 即等边）。
