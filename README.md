# Geometry Sketch — 中学数学辅助画图skill

> 根据初中数学几何题的**纯文字描述**，自动计算坐标并绘制几何图形，输出 **可交互 HTML + PNG**。基于通用 Agent Skill 体系 ，适用于教师出题配图、学生习题作业可视化、试题解析配图等场景。

---

##  它能做什么

```
输入: "如图，在正方形ABCD中，AB＝4，对角线AC上的有一动点P，以DP为边作正方形DPFG．
       下列结论：①在P点运动过程中，F点始终在射线BC上；②在P点运动过程中，∠CPD可能为135°；
       ③若E是DC的中点，连接EG，则EG的最小值为根号2；
       ④△CDP为等腰三角形时，AP的值为2根号2或4根号2－4．其中结论正确的是."
输出: 一张默认位置 PNG + 一个可拖拽动点的交互 HTML
无需多余提示词，输入完整的题干即可出图
```

- 无需任何人工坐标计算——解析约束 → 判定模式 → 计算坐标（含动点参数化、关联点推导）→ 约束验证 → 绘图
- 对图不满意可直接文字反馈（"不需要连接OP"、"角C标直角标记"、"加一条角平分线"、"AB使用虚线"），迅速响应修改

##  特性亮点

| 特性 | 说明 |
|------|------|
| **四模式自动判定** | 精确（几何关系唯一确定）/ 示意 / 坐标系 / 动点（可拖拽交互）——无需手动指定 |
| **双渲染路径一致** | PNG（matplotlib）与 HTML（SVG+JS）共用同一数据源（`segments`/`circles`/`curves`/`points`/`dynamics`），所见即所得 |
| **动点交互** | 多动点并行拖拽、关联点实时联动（对称/中点/平移/交点等 14 种几何关系 op）、轨迹显示、实时读数 |
| **交付检查** | 保存前自动执行 8 类检查（线段完整性 / 标签豁免交叉 / 孤点 / 拆段顺序 / 画布边界 / 曲线越界 / 动点 op·type 合法性 / 开放图形覆盖），易错用法即时告警 |
| **个性化调整** | 图形支持镜像、旋转，字母标识支持八方位选择，高度个性化 |

##  支持内容

- **三角形**：一般、等腰、等边、直角（SSS / SAS / ASA / 高线 / 角平分线 / 中线）
- **四边形**：平行四边形、矩形、菱形、正方形、梯形
- **圆**：圆心半径、直径、外接圆、内切圆、切线、圆弧、扇形
- **曲线**：一次函数、反比例函数、抛物线等（采样成折线渲染）
- **坐标系**：x/y 轴箭头 + 原点 O（不标数字，保持题面纯净）
- **变换**：翻折（对称点）、旋转、平移、缩放
- **辅助**：高线、中线、角平分线、垂直平分线、翻折折痕、虚线（拆线规则）
- **动点**：圆上 / 线段上 / 直线上 / 坐标轴 / 曲线上（抛物线等）——多动点并行、关联点链式派生

##  模式识别（skill 自动判定）

| 模式 | 触发条件 | 行为 |
|------|----------|------|
| **精确**（默认） | 几何关系能唯一确定形状 | 计算坐标 + 逐条约束验证（偏差 <1%） |
| **示意** | 约束严重不足 / 题面说"示意图" | 合理默认值（三角形 60°/50°/70° 等） |
| **坐标系** | 含"一次函数/抛物线/x轴/y轴/坐标"等 | 画轴箭头与轴标注 + 原点 O |
| **动点** | 含"动点/在…上运动/滑动/绕…旋转"等 | 默认位置 PNG + 可拖拽交互 HTML |

##  交互式 HTML

- **视图控制**：旋转（滑块 / 90°/180°/270°）、水平/垂直镜像、缩放、左右平移（与旋转/镜像正交）
- **标注控制**：标注距离、轴标注距离（x/y/O 方位固定、距离可调）、字号、点击标签循环切换 8 方位
- **动点模式**：进入调整模式后可**拖拽动点**（沿圆/线段/直线/曲线约束滑动，曲线动点最近邻吸附）；每个动点有参数滑块双向同步；勾选"显示轨迹"查看动点与关联点轨迹；调整模式下视图控件自动锁定（保存 PNG 保留可用）

##  薄壳化架构

```
geometry-sketch/
├── SKILL.md             ← 导航骨架（约 10KB，含硬规则速查 + 工作流 + 阅读路线图）
└── references/          ← 代码/规则权威源（薄壳化后唯一存在处）
    ├── algorithms.py    ← 3.1 几何算法库（坐标求解、交点、动点 op 求值器）
    ├── template_static.py   ← 4.1 静态模板（精确/示意/坐标系，PNG + HTML 双端）
    ├── template_motion.py   ← 4.1b 动点模板（dynamics 参数化 + JS 交互内核）
    ├── rules.md         ← 阶段 0-5 详细规则（模式判别/构造策略/op 表/反馈表）
    └── type-notes.md    ← 常见题型构造参考
```

- Skill 生成脚本 = `algorithms.py` 全文 + 所选模板（须整文件逐行复制，勿重组删减模板内部函数）
- 两条渲染路径（PNG / HTML）共用数据源，几何表达一律走数据区（`segments`/`curves`/…），扩展区仅作装饰

##  交付检查

| # | 检查 | 级别 |
|---|------|------|
| 1 | `required_segments` 题面条目线段完整性（缺失自动补入） | FAIL |
| 2 | `label_exempt` × 题面结构点交叉（核心点误豁免→双端缺标签） | WARN |
| 3 | 孤点检测（deg<2 自动补连最近点） | WARN |
| 4 | 拆段顺序（首尾相接共线段中间点段内判定，防跨点/重叠） | WARN |
| 5 | 画布边界（点+圆完整在画布内） | FAIL |
| 6 | 曲线越界（坐标系题） | WARN |
| 7 | 动点 op / params type 合法性（防 HTML 端 TypeError） | FAIL |
| 8 | 开放图形覆盖动点可达范围（B2，动点拖不出图形） | FAIL |

##  风格约束（硬规则）

- 全黑等宽实线（`#000000`、1.5pt），白色背景
- **默认不画任何标记**（无直角标记、等长标记、角度弧线；用户明确要求时可选进行添加）
- 坐标系不标刻度数字
- 动点模式 PNG 画默认位置
- 最长边水平、高瘦图形横放（自动方向归一化）

##  环境依赖

##  输出文件

| 格式 | 用途 |
|------|------|
| `.png` | 300dpi 位图，默认位置静态图，直接插入 Word/PPT |
| `.html` | 可交互图，浏览器打开：旋转/镜像/缩放/标注调整（静态），保存为PNG ；拖拽动点/轨迹 |


## ⚠ 已知限制
训练与测试使用初中数学七至九年级习题，暂未测试高中数学、高等数学等。暂不支持三维图形。
